BACKEND:

1.Open a terminal and go inside the backend folder.

2.Run this command: uvicorn main:app --reload

3.This starts your Python server on [http://127.0.0.1:8000](http://127.0.0.1:8000). It will wait patiently for the frontend to ask it to do something.

-> .\env\Scripts\activate: YES, but only for new windows. You must run this anytime you open a brand new terminal window in VSCode to work on the backend. If you already see (env) in green, you are good to go.

-> uvicorn main:app --reload: YES. This is the literal "start button" for your backend. You need to run this whenever you sit down to work and want to turn the server on.

uvicorn main:app --reload



FRONTEND :

1.Open a second terminal and go inside the frontend folder.

2.Run this command: npm run dev

3.This gives you a link (usually http://localhost:5173). Open that in your web browser to see your website.
